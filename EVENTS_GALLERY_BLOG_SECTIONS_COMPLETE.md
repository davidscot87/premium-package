## Common Design Elements

### Color Scheme
- Primary: #1e3a8a, #1e40af (blue gradient)
- Secondary: #0d47a1
- Accent: #fbbf24, #f59e0b (gold gradient for featured badges)
- Text: #0f172a (dark), #64748b (light)
- Background: #ffffff (white), #f9fafb (light gray)

### Typography
- Headings: 800 weight, clamp() for responsive sizing
- Body: 400-600 weight, 1.6-1.8 line-height
- Consistent font sizing across all pages

### Spacing
- Section padding: 3-6rem vertical
- Grid gaps: 1.5-3rem
- Card padding: 1.5-2.5rem
- Consistent spacing system

### Animations
- Hover transforms: translateY(-8px to -10px)
- Image zoom: scale(1.1-1.15)
- Transition duration: 0.3-0.6s
- Easing: cubic-bezier(0.4, 0, 0.2, 1)

### Shadows
- Cards: 0 4px 20px rgba(0, 0, 0, 0.08)
- Hover: 0 12px 40px rgba(0, 0, 0, 0.15)
- Featured: 0 10px 40px rgba(0, 0, 0, 0.1)

### Border Radius
- Cards: 20-25px
- Buttons: 50px (pill shape)
- Badges: 20-50px
- Images: 15-20px
